# itch.io screenshots

Upload the six numbered PNGs in this folder to the itch.io project's
**Edit game → Screenshots** section, in filename order.

1. **Main Menu** — title screen and sector selection.
2. **Orbital Graveyard** — fighters, hostile fire and an explosion.
3. **Veil Nebula** — crystal-lined corridor and a bullet barrage.
4. **Imperial Foundry** — industrial scenery and an enemy formation.
5. **Stellar Citadel** — cathedral backdrop and incoming fire.
6. **Graveyard Crossfire** — a later wave with player and enemy shots.

All images are 1280×1024 RGB PNGs: actual 320×256 A500 game captures
enlarged 4× using nearest-neighbor scaling. The complete screen and HUD are
preserved, with no promotional overlays or fabricated gameplay.

These come from the existing ordinary-play trailer captures and a release-validation
main-menu capture, not a new build of the working tree. `manifest.json` records
the source disk hashes (the menu uses a separate build), hardware,
capture paths and image hashes. The PNGs are self-contained; uploading them
does not require the local `.tmp` capture directory.
